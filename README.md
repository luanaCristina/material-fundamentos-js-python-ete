# Material completo de fundamentos — JavaScript, Python, APIs, MongoDB e Git

Material didático para alunos do primeiro módulo da ETE.

O objetivo é aprender a **entender, pesquisar, adaptar e testar**, sem depender de decorar todos os comandos.

## Documento principal

- [Material completo de fundamentos](docs/MATERIAL_FUNDAMENTOS_JS_PYTHON_API_GIT.md)

## Conteúdos

- sintaxe de JavaScript e Python;
- variáveis, constantes e tipos;
- escopos, shadowing e nested scopes;
- arrays, listas, vetores, matrizes, objetos e dicionários;
- operadores, condicionais e laços;
- funções, `def`, arrow functions, `lambda`, IIFE e módulos;
- métodos de arrays, listas, objetos e dicionários;
- APIs, cliente, servidor e métodos HTTP;
- MongoDB, MongoDB Atlas e CRUD;
- bibliotecas, pacotes e imports;
- Node.js, Python, npm, pip e ambientes virtuais;
- servidores, portas, localhost e ambientes;
- Git, GitHub, branches, commits e push;
- exercícios, projeto final, gabaritos e referências oficiais.

## Como estudar

1. leia uma seção curta;
2. digite os exemplos em vez de apenas copiar;
3. execute no terminal;
4. altere os valores;
5. provoque um erro de propósito;
6. leia a mensagem do erro;
7. consulte a referência oficial;
8. resolva o exercício sem olhar o gabarito;
9. registre o que aprendeu.
