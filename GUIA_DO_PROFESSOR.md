# Orientação de uso em aula

## Proposta

Este repositório contém o material completo de fundamentos de programação usado nas aulas da ETE. Ele foi organizado para que os alunos pratiquem a mentalidade de investigação:

- formular uma hipótese;
- executar um exemplo;
- observar a saída;
- pesquisar a sintaxe;
- comparar JavaScript e Python;
- corrigir erros;
- explicar a decisão tomada.

## Sugestão de sequência

### Aula 1 — ambiente e terminal

- instalar Node.js, Python, Git e VS Code;
- executar o primeiro arquivo nas duas linguagens;
- explicar pasta atual, terminal e `PATH`.

### Aula 2 — variáveis e tipos

- apresentar `let`, `const`, `var` e convenções Python;
- usar `typeof` e `type()`;
- propor o cadastro simples.

### Aula 3 — coleções e escopo

- arrays/listas;
- objetos/dicionários;
- escopo local/global;
- shadowing;
- exercício de boletim.

### Aula 4 — controle de fluxo e funções

- condicionais;
- laços;
- funções com parâmetros e retorno;
- funções em arquivos separados.

### Aula 5 — métodos e módulos

- `map`, `filter`, `reduce`;
- compreensão de listas;
- `require`, `import`, `pip` e `npm`.

### Aula 6 — API e servidor

- cliente e servidor;
- portas e localhost;
- rotas e status HTTP;
- primeiro servidor Express ou Flask.

### Aula 7 — MongoDB

- documentos e coleções;
- Atlas;
- CRUD;
- variável de ambiente e `.env`.

### Aula 8 — Git e GitHub

- `init`, `status`, `add`, `commit`, `remote`, `push`;
- branches;
- README;
- projeto final.

## Dinâmica recomendada

Não entregue o gabarito antes da tentativa. Peça que cada aluno responda:

1. o que o código deveria fazer?
2. qual parte ainda não entende?
3. qual palavra pesquisaria?
4. o que o erro está dizendo?
5. como provaria que a correção funcionou?

## Avaliação

Avalie mais do que o resultado final:

- organização;
- nomes das variáveis;
- capacidade de explicar;
- uso de documentação;
- qualidade dos testes;
- tratamento dos erros;
- histórico de commits;
- segurança com variáveis de ambiente.
